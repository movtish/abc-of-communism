# English paper

[ABC_of_Communism.pdf](ABC_of_Communism.pdf) contains the English paper and appendix. `ABC_of_Communism.tex` is the main text, `appendix.tex` the appendix and `refs.bib` the bibliography. The two supplementary TeX files report the 1924 and 1959 evidence. Tables and number macros are generated from saved estimates. Build instructions are in [docs/BUILD_STATUS.md](../docs/BUILD_STATUS.md).
