Данные, которые пока не получены в пригодном для идентификации виде:

- Полная панель фактических открытий ликпунктов, уникальных учащихся, посещений, завершения и результатов экзаменов по одинаковым территориям за 1920–1930-е.
- Одновременный разрез миграционных потоков по возрасту, полу и грамотности с полной регистрацией.
- Проверенное территориальное соответствие всех единиц трёх переписей.
- Индивидуальная историческая цепочка «обучение матери в ликбезе — образование её ребёнка — современные потомки».

Это результат проведённого поиска, а не доказательство отсутствия таких документов. Для причинной проверки механизмов приоритет имеют архивные отчёты ВЧКЛБ и местные документы об исполнении; для немедленного расширения описательной проверки уже пригодны данные 1959 года.
