Дополнительные данные и воспроизводимый анализ

Начните с ADDITIONAL_DATA_ANALYSIS_RU.md. Реестр интернет-источников и фактической доступности находится в DATA_SOURCES_RESEARCH_RU.md.

Исходная статья и GitHub не изменены. article_addendum.tex — подготовленный фрагмент обсуждения результатов, который ещё не включён в статью и не проверен компиляцией полного документа.

Содержимое:

- raw_sources: скачанные источники. XLS и PDF сохранены без изменения; региональные HTML-таблицы Демоскопа перекодированы в UTF-8 без редактирования таблиц. Здесь также находятся публикации о миграции и бюджетах времени, сканы исторических изданий. Полный псковский выпуск не скачан: есть описание и несколько страниц.
- inputs: исправленная таблица 1939 года из предыдущего аудита. Её выбранные значения дополнительно сверены с заново скачанными источниками.
- census1959_regions_long.csv: 20 025 записей. Ключ — region_id, area, sex, age. Значения area: total/urban/rural; sex: B/M/F. Внутри файла сохранены исходные номер строки и номер первой колонки Excel.
- census1959_partition_checks.csv, census1959_population_checks.csv, census1959_html_xls_checks.csv, census1939_online_checks.csv: результаты сверок. Они проверяют перенос и внутренние равенства, не истинность исторических ответов респондентов.
- linked_republic_cohorts_1939_1959.csv: 216 наблюдений, включая четыре возрастные группы; основной сводный анализ использует первые три.
- republic_summary_1939_1959.csv, persistence_sample_summary.csv: региональная и выборочная сводки; возрастные веса зафиксированы по 1939 году.
- post1939_gender_gap_inference.csv: все 12 моделей, CR1, CR2/Satterthwaite, jackknife, исключение одного кластера и restricted wild cluster bootstrap.
- migration_*.csv: извлечённые показатели источников с сохранёнными предупреждениями о заголовках и единицах.
- time_use_1923_domestic_work.csv: домашний труд из маленького воронежского обследования; время приведено к минутам.
- literacy_persistence_regions.png: график описательной региональной динамики.
- scripts: извлечение и анализ. source_file_manifest.json содержит размеры и SHA-256 скачанных файлов; validation_summary.json — результаты основных проверок.

Грамотность 1959 вычисляется для возрастов от 9 лет как:

    100 × (население − не указавшие образование − неграмотные)
          / (население − не указавшие образование).

В отдельных образовательных категориях исходного XLS пустая клетка признаётся нулевой только при точном исчерпании общей численности известными неотрицательными компонентами. Флаг source_blank_fields сохраняет исходные пропуски, а blank_zero_identified_by_partition отмечает такой вывод. Для строки «всё население» грамотность не вычисляется, поскольку её знаменатель включает детей младше 9 лет. Открытую группу 70+ нельзя использовать для восстановления отдельных пятилетних когорт.

89 территориальных записей включают национальный итог и вложенные округа. Нельзя суммировать их все. Записи рабочих блоков Ленинграда после region_id=89 исключены. Для регионального анализа использованы девять неперекрывающихся республик; малые территориальные передачи между переписями ещё не гармонизированы.

CSV записаны с разделителем-запятой, десятичной точкой и кодировкой UTF-8 с BOM. При открытии в русской версии Excel при необходимости укажите разделитель-запятую через импорт текста.

Для воспроизведения из распакованной папки с Python 3:

    python -m pip install -r requirements.txt
    python scripts/analyze_new_data.py
    python scripts/verify_1939_values.py
    python scripts/estimate_post1939.py
    python scripts/make_plot.py

Сеть после установки зависимостей не нужна: входные файлы включены. Скрипты перезаписывают только подготовленные результаты внутри этой папки. Исторические оригиналы в raw_sources не меняются. Для оценки используется полный перебор 32 или 512 знаковых множителей, а не случайный отбор части векторов. Фиксированные эффекты переоцениваются под ограниченной нулевой гипотезой.

Территориальные изменения, несвязанные индивидуальные наблюдения, изменение определения грамотности и качество административного учёта остаются ограничениями данных. Новые модели оценивают динамику после 1939 года и не являются новыми причинными оценками ликбеза 1926–1939.
