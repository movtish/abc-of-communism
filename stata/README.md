# Stata replication

`ABC_of_Communism.do` estimates the main specifications in Stata. First run `python scripts/export_stata.py` from the repository root to create `stata/data/*.dta` from the Python analysis cells. `scripts/compare_stata.py` compares saved Stata and Python estimates. Running the do-file requires a licensed Stata installation.
