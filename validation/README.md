# Source and numerical checks

`fresh_source_matches.csv` checks the 1939 population and illiteracy inputs. `scope_corrections.csv` records the city-oblast adjustments. `1939_unresolved_70plus_cells.csv` preserves seventeen inconsistent source cells outside the analysis windows. `number_changes.csv` records changed numerical keys. JSON records report release checks, runtime versions and manuscript builds. `source_checks/` contains the source pages used in the comparisons.
