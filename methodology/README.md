# Inference and accounting

`inference.py` implements CR1, CR2, the cluster jackknife and the restricted wild bootstrap. `run_analysis.py` estimates the cohort specifications. `accounting.py` calculates selection and exposure scenarios. `test_inference.py` checks the numerical implementation. `results/` contains the current outputs; `results_original/` retains the earlier comparison outputs.
